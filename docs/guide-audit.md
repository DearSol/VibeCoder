# Interface and capability audit

The uploaded app guide is the target, not evidence that every feature exists. This audit records the actual implementation after the PC interface review.

| Guide requirement                                             | Current implementation                                                                                                                                                                         |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Distinct Fill, Remove, Expand, Local Patch                    | Visible modes above the canvas; each connects to its corresponding operation.                                                                                                                  |
| Grouped lassos                                                | Freehand, polygonal, and magnetic share a flyout. Magnetic uses nearby color-edge snapping and needs visual evaluation on difficult images.                                                    |
| Rectangular and elliptical marquee                            | Share a flyout; Shift constrains the shape.                                                                                                                                                    |
| Brush, replace/add/subtract, all/invert/clear, inward feather | Implemented in document coordinates with history.                                                                                                                                              |
| Readable, adjustable interface text                           | Labels increased from the initial 8–11px sizing; Standard/Large/Larger preferences affect interface text separately from canvas zoom. Layers remain visible below scrollable editing controls. |
| Expand edges/corners/exact pixels                             | Eight handles, four margin fields, proposed dimension display, reset, protected original pixels, review and acceptance as one history change.                                                  |
| Multiple provider accounts                                    | Separate session keys and adapters for OpenAI, Gemini, OpenRouter, experimental Kie Nano Banana Pro. Keys remain outside projects.                                                             |
| Reference-guided inpainting                                   | Up to four references supplied in stable order. Accepted edits retain reference assets, prompt, provider, and model in projects.                                                               |
| Alternatives                                                  | One result per request currently. Two to four retained alternatives remain planned.                                                                                                            |
| Comparison                                                    | Aligned Original toggle implemented. Before edit and draggable split comparison remain planned.                                                                                                |
| Projects and PNG                                              | Implemented, including generated layers/reference assets and expanded dimensions. Undo history is session-local.                                                                               |
| Seam blending                                                 | Local repair: Poisson or Feather. AI Fill/Remove: None (default), Feather, or Poisson. No automatic Poisson on expansion.                                                                      |

Still outstanding from the full guide: grow/shrink/move selection, dedicated mask view and mask save/load, kept-layer mask refinement, crop/orientation/placement tools, expansion aspect presets and overlap bands, alternative groups, compatible-model catalog discovery/refresh, additional Kie schemas (including Seedream), Stability AI, MobileSAM, crash recovery and saved job recovery, a measured 64-megapixel workflow, native Windows AI access and Credential Manager, and Windows installer validation.

The npm app provides a localhost Node AI service for PC testing. This extends the original browser-preview scope; it does not complete the native desktop integration. Entered keys are session-only unless the user opts into a local plaintext `.env.local`. The portable static preview has no AI service.

Validation distinguishes deterministic app behavior and simulated provider responses from live AI generation. Live provider checks, model availability, visual alignment/reference fidelity, and Windows performance are unverified. Kie's official documentation was blocked by the cloud network policy; its adapter is explicitly experimental rather than certified compatible.
